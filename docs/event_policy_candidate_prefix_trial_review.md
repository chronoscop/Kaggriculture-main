# candidate_prefix 第20轮复盘

## 实验结论

20轮完成，没有晋级。新采集确实覆盖了候选自己的真实后续状态，但没有证明整套经营策略稳定提升。不建议原样长训或直接扩到batch范围。

第5轮初筛：候选/冠军均70.83%。第10轮初筛75.00% vs66.67%，随后冻结第10轮候选继续独立复核。第20轮结束时累计32个复核种子、每策略192局，候选63.54%、冠军68.23%，差-4.6875个百分点，改善检验p=0.8853，拒绝晋级。不是现金门槛拦住了胜负改善；也不能把此结果当成最新第20轮网络的独立评估。尚不能据此宣称统计显著退步。

## 已确认的数据问题

160个训练条件，冠军和候选合计320条完整基础轨迹；828条局部对照，其中320条来自候选真实前缀，228条为候选后续修订。采集耗时1663.91秒，更新4.14秒，816711模拟步约1135.9局完整模拟工作量，另有488局评估。

候选后续228条：

- 204条（89.5%）备选计划与该scope首次安排的完整参数相同。
- 184条（80.7%）A/B双方终局现金完全相同，均属于上述同参数重提。
- 215条（94.3%）不改变胜负，8条改善、5条恶化。
- 备选208条是一格小麦。网络首选非Keep时，采集优先比较它与Keep；这种机制在首选重复已有计划时，持续消耗分支预算。

实际例子：第1轮seed280000、座位0，第25步已经决定一格小麦、提前24步备料、现金保留197.82；第49步Material事件再次提交相同安排。保持和重提都以55557:47000结束。

现金完全相同不能证明所有中间执行状态都相同。尤其204条同参数重提中有20条改变了终局现金：`Controller::revise_batch`会替换链接并重建进度。不能粗暴按参数相同删除候选，更不能按事后是否获胜筛选经验。应先定义基于真实剩余义务、进度和预约的计划差异，再在分支前辨别有效备选。

全体828条中689条（83.2%）没有胜负差异。平局标签本身正确；问题是花大量模拟比较缺少经营差异的方案，不能靠反复拟合这些标签发现条件化生产策略。

## 连续段与网络健康

320条段记录中90条实际有后续事件；其中C和B终局现金相同58条，胜负相同84条，额外后续选择改善3条、恶化3条。这里没有支持“组合破坏是唯一主要原因”的证据；也没有稳定有利的连续段改善信号。段结果目前仅用于诊断，不给其中每个动作摊派监督标签，这是应保留的约束。

末轮输入最大绝对值小于1，第一层饱和比例0，context梯度范数0.02946；未发现重现此前输入饱和。经验上的末轮非零目标排序准确率约58.5%，不能称为稳定学准。

后5轮候选后续选择：122次一格小麦、32次Keep、2次一格胡萝卜。可选择多种生产，不等于已经学到丰富的条件化经营。该统计是训练局面行为，不能单独判断最优品种。

## 下一步应修的闭环

保持真实候选前缀、统一胜负目标、稳定继续策略和独立验收。集中修复探索预算分配到什么经营差异：

1. 在候选里明确表达相对已有承诺的变化：品种、剩余数量、真正启动时点、资金/材料/工时需求，以及是否重置进度。没有实际差异的重申与Keep统一；明确的延期/重排必须独立保留其真实含义。任何执行语义变化都需新契约，不能重解释旧部署。
2. 首选已被覆盖或只是重申时，把后续采样预算用于另一项实质不同且可执行的方案。按执行前的资源缺口、生产差异及证据覆盖选择，保留改善、失败和无胜负差异的结果；不能事后只留获胜样本。
3. 分开检查发现与学会：在已采到非零胜负差异的同局面对照上，核对网络是否选中较好方案；对真实有意义的连续安排保留整段验收。若已知差异仍拟合不好，应先查学习/表示，不靠增加模拟掩盖。

这是本轮数据支持的下一步，不等于已经证明这些修改能带来强度提升。上一轮回归测试验证了采集和保护机制，却没有验证分支预算产生了足够的有效经营差异；这次检查补出了该缺口。
