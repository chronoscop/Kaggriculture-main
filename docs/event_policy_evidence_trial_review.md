# event_policy_evidence_trial：100轮只读复盘

本轮只分析日志、代码和已保存权重，未修改策略或启动训练。目标仍是720回合终局比赛得分；现金仅作诊断。

## 实际结果

100轮，1600局基础轨迹，4565条终局比较，日志累计采集/更新/评估约6473秒。第30轮冻结候选于第40轮通过第三次独立复核：32个独立种子，每个策略128局，对既定对手组得分率62.5%→87.5%，配对种子检验p=0.000213623，alpha=0.016667。这支持一次对该评估分布的改进，不等于比赛总体胜率。

固定8局规则对手监测：初始现金60539.125、得分率75%；晋级后55085、100%。没有证据说绝对赚钱更多，但不能说比赛能力完全没提升。第41–100轮无新晋级。第65轮候选在扩大到32种子、每策略192局后增益归零；第95轮独立复核增益-0.020833。不能把停滞归因于p值门槛。

最后20轮更新后首选：首次安排320个局面，保持0；已测304个，16改善、13退步。后续修订419个局面，保持0；已测405个，11改善、19退步，平均得分差-0.017284。训练记录上的指标不是独立验证，但说明当前实际选择仍未稳定有益。

## 新确认的数值问题：局面编码严重饱和

源码：`native/src/pipeline/plan_events.rs`将市场库存除以100放入context；本轮末20轮905条对照中，9个库存输入的平均绝对值为98.59–100.80。`native/src/learning/policy.rs`在context的两层全连接后使用tanh。

用NumPy按实际权重、tanh、拼接顺序及残差分数复算。最终网络第100轮当批对照MSE=0.259595844，原生日志0.259595871；非零标签方向正确率均为0.538461538，核对一致。

在相同905条末期记录上，最终网络第一层所有单元绝对激活均大于0.99；第二层任一维跨记录的最大跨度仅0.00005886。并非严格常量：仍有455个不同编码。初始化网络最大跨度0.037607，第30轮网络0.00085495；这是同一组输入上的权重对照，不是不同阶段状态分布比较。

因此，完整局面分支携带的区分信息已被严重压缩。候选特征仍带价格、可用现金、工时和部分事件信息，不能说模型完全看不到状态。该问题与学习偏好固定接法相符，但尚未修正并做对照，不能断言解释全部停滞。

最终网络在末20轮739个唯一记录局面上：594次小麦、112次胡萝卜、33次取消、0次保持。此为最终网络在已采集训练状态上的复算，不是新完整对局。

## 结论与下一步

上次修复消除了结果依赖的回放筛选，却遗漏输入尺度和激活有效性检查。通过执行回归不意味着网络能够有效利用条件信息；这是本次检查新增的实质缺口。

优先对市场库存等输入按实际数量级统一归一化，保留库存相对基准的变化信息，并检查所有特征范围及网络激活/梯度。特征变化须版本化，保留旧已验收策略的旧编码执行；不能直接用新输入解释旧网络。新学习器先证明能区分同类候选在不同真实资源/承诺条件下的收益，再做现有整局独立胜负验收。

本轮不建议原样延长训练，不降低门槛，不更换对手池，不添加现金奖励。采样修正、归一化都不单独保证多次经营改动组合后有益，完整验收仍需保留。
