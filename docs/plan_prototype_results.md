# 经营计划原型：实验结果与运行方式

2026-09-27。最小原型已实现并运行。它检验批量投入、执行承载能力、商品价值评分、完整赛季参数搜索和提前备种；不是已经完成的分层神经网络 RL，也没有证明长期 PPO 收敛。

## 逻辑复核后的范围

- 当前 Project/Route 本来已有一定层级。仅增加一个 Plan 类型没有可验证收益，所以原型先修改真正影响行动的环节。
- 新投资按现金、材料、简化工人承载能力和紧凑位置组成批次，复用现有项目落实与路线回执机制。
- 提供独立经济路线评分入口。考虑收获商品价值、养护与建立生产的估计价值；用于选择，绝不作为真实奖励。
- 运营与扩张资金分别检查，继续按实际库存执行；报价保守估算，订单失败仍需后续观察确认。
- 完整赛季参数搜索调整经营配置；按胜负得分率、再按现金差排序。所有候选在一轮内面对相同种子、双方座位和冻结对手。
- 学习成功后使用确定性配置运行，没有“训练随机策略赚钱、提交贪心策略空转”的执行切换。这只消除了该原型的一类问题，不等于解决未来神经网络版本的全部问题。

现有 `mixed-train` 的候选接口和旧检查点保持原语义。新原型由 `plan-prototype` 单独运行，不能把其参数 JSON 当作 PPO 权重传给 `mixed-train`。

## 小实验

对手为 `mixed_v8_market3_rule_trial/best.json`，第40轮冠军。

### 1. 初筛与路线评分对照

训练探索种子810001、810002，交换座位，每组4局：

| 配置 | 终局现金均值 | 对手现金差均值 | 胜局 |
|---|---:|---:|---:|
| 原型，旧路线评分 | 40356.50 | +12823.50 | 4/4 |
| 原型，经济路线评分 | 47748.00 | +19909.25 | 4/4 |

现有冠军自对弈作执行控制，平均现金49718.50、平均现金差0。这与原型是不同市场轨迹，不用于直接比较自身现金高低。

原型前两天实际生产21格，生产峰值约52格；冠军控制分别为4格、13格。此处不是采购请求或批准项目数。

### 2. 完整赛季参数搜索可以带来改进

两轮、每轮4个配置、每配置4局，共32局搜索。独立复核910001、910002，双座位4局，初始和最终配置各跑一次：

| 配置 | 复核现金 | 复核现金差 | 胜局 |
|---|---:|---:|---:|
| 搜索前 | 39916.25 | +16033.50 | 4/4 |
| 搜索后 | 47156.00 | +31939.50 | 4/4 |

这证明了一次小实验中的可优化性，不是普遍收敛证据。

### 3. 额外四种子复核与提前备种

820001–820004，双座位，每配置8局：

| 配置 | 平均现金 | 平均现金差 | 胜局 |
|---|---:|---:|---:|
| 初始原型，旧路线评分 | 47108.375 | +22938.875 | 8/8 |
| 初始原型，经济路线评分 | 55631.375 | +25339.250 | 8/8 |
| 参数搜索结果 | 63552.750 | +36689.875 | 8/8 |
| 参数搜索结果 + 提前一天备种 | 68503.750 | +40880.375 | 8/8 |

提前备种对照仅改变 `renewal_lead_days`：0→1。平均成功续种199→207.75，平均过期项目0.625→0.125；两组非法/失效动作计数均为0。零计数只是这些局的结果，不保证所有情况下无失败。

这批种子被用于多项工程比较，因此是复核/验证集，不再称作最终未见测试集。后续命令另用新的训练与确认种子。

### 4. 强参考仍是未解决的差距

种子80000991交换座位，原型初始配置对 farm2945 两局均输：我方20008，对方118199。原型已有172次续种，但间隔中位数11回合；参考同为172次，间隔中位数1回合。这是加入提前备种对照的依据。

不能根据“打赢旧模型”声称已经接近DECEM，也不能把供给扰动后的自身现金与不同对手对局混成一个分数。

继续在同一种子换座对照，搜索后的配置结果如下：

| 配置 | 我方平均现金 | 参考平均现金 | 平均现金差 | 续种/局 | 3回合内续种/局 |
|---|---:|---:|---:|---:|---:|
| 搜索结果，提前量0 | 32140.0 | 131112.0 | −98972.0 | 229 | 144 |
| 搜索结果，提前量1 | 25448.5 | 126045.5 | −100597.0 | 304 | 301 |

提前备种使接续更顺，却没有在强对手上增加收益。两个配置续种间隔中位数均为1，因此默认保留提前量0，允许后续搜索探索0–2。这个反例说明不能把续种次数/速度直接当奖励。对强参考仍只有一个种子，不能据此估计总体胜率或断言提前备种普遍无用。


## 实现文件

- `native/src/pipeline/plan_prototype.rs`：确定性批次经营、预测价格情景、容量估计、采购与备种。
- `native/src/pipeline/planner.rs`：可选经济路线评分及按商品的收获量记录；原有路线入口保留排序逻辑。
- `native/src/bin/plan-prototype.rs`：完整对局评估、参数搜索、JSONL agent入口。
- `native/configs/plan_prototype_v1.json`：上述搜索结果的可复现实验起点，提前备种保持为0。

已通过28个Rust库测试，覆盖原有执行器/市场约束及新增的真实开局生产、公开观察隔离、商品价格改变路线选择、提前备种与旧配置兼容。`git diff --check`通过。

## 历史原型命令：640局参数搜索（已完成，不是当前训练入口）

这是CPU上的经营参数搜索，使用7个并行环境工作线程。GPU神经网络更新尚未接入该原型。旧神经网络只作为冻结对手推理。

构建：

```bash
cargo build --manifest-path native/Cargo.toml \
  --bin plan-prototype --release --features train --offline -j 4
```

当前环境若cargo不在PATH：

```bash
export PATH=/tmp/route-rl-rustup/toolchains/stable-x86_64-unknown-linux-gnu/bin:$PATH
export CARGO_HOME=/tmp/route-rl-cargo
```

在screen中运行：

```bash
native/target/release/plan-prototype search \
  --config native/configs/plan_prototype_v1.json \
  --checkpoint runs/mixed_v8_market3_rule_trial/best.json \
  --opponent-config native/configs/plan_prototype_v1.json \
  --out runs/plan_prototype_train1 \
  --rounds 6 \
  --population 6 \
  --workers 7 \
  --seeds 8500001 8500002 8500003 8500004 \
  --seed-stride 100 \
  --confirm-seeds 9500001 9500002 9500003 9500004 9500005 9500006 9500007 9500008 \
  --search-seed 2026
```

- 两类冻结对手：rule40与原型起点；原型不会在该轮搜索中偷偷替换自己作为对手。
- 每轮所有候选使用同一批训练种子；下一轮整体+100。精英配置也重新评估。
- 搜索6×6×4种子×2座位×2对手=576局；初始/最终确认各32局，共640局。
- 对手原型分支需要更多路线规划；不要直接用旧PPO每轮时间估计本命令耗时。
- 输出目录需全新，避免覆盖旧搜索记录。可用`--config`开新目录继续搜索，但它不是恢复完整PPO优化器或种群状态。

主要输出：

- `search.jsonl`：每配置、每局和汇总表现。
- `initial.json`：起点；`latest.json`：最后一轮训练选择。
- `round_XXXX.json`：各轮选择，便于保留中间结果。
- `initial_confirmation.json` / `confirmation.json`：相同确认种子上的起点与最终候选。
- `best.json`：确认得分率不下降且平均现金差提高才替换起点；否则保留起点。它不声称是所有中间轮次在所有对手上的最强策略。

已实测新种子轮换、冻结原型对手及拒绝替换路径：`plan_prototype_v1_pool_smoke`确认无改善，`best.json`保持与`initial.json`一致。少量确认局有噪声，该规则不是统计意义的单调改进保证。

## 还未完成的部分

- 未来工时仍是简化承载估计，没有完整的跨日服务预约求解。
- 土地转产、连续作物退出和预测不确定性处理仍不完整。
- 模型尚未学习状态到计划的神经网络选择；没有实现新的PPO能力保持项。
- 目前完整赛季参数搜索的样本规模小，对强参考的泛化仍需改善。

原型验证已完成。新的模型训练入口见 [plan-rl-v1](plan_rl.md)，使用 `plan-train`；下面的参数搜索不再作为下一步训练建议。
