# 冠军挑战、行为多样性和受保护经验（v7-league-3）

> 最新对手调度见 [近期快照与动态历史对手](mixed_v7_pfsp.md)（v7-pfsp-4）。近期模型每 10 轮冻结，历史抽样按战绩调整；旧版固定角色配额和行为新颖性入池规则已替换。

此修订可恢复原版 v7、v7-retention-2 和本版本的完整检查点；保留网络、Adam、随机状态和已有对手权重。策略输入/动作契约、现金奖励和 PPO 算法不变。`best.json` 的选择规则已更新，跨版本比较请另用共同的独立测试集。

## 从第 1885 轮增量实验

确认 `runs/mixed_v7_retention_long/best.json` 中 `iteration` 为 `1885`。使用新目录；下面到 **1985 轮，即新增 100 轮 / 3200 局采集**。200 轮实验把 `--iterations` 改为 `2085`（新增 6400 局采集）。轮数仍是累计上限。

```bash
mkdir -p runs/mixed_v7_league_trial

native/target/release/mixed-train \
  --out runs/mixed_v7_league_trial \
  --resume runs/mixed_v7_retention_long/best.json \
  --iterations 1985 \
  --games-per-update 32 --workers 7 --device cuda \
  --epochs 2 --batch-size 256 --seed 1200 --opponent league \
  --eval-every 5 --eval-games 8 --eval-seed 1000000000 \
  --exploration 0.2 --imitation-weight 0.05 \
  > runs/mixed_v7_league_trial/train.log 2>&1
```

可在 screen 中前台执行。首次恢复旧模型会出现 `profile_opponent` 阶段：对缺少行为资料的历史模型逐一做固定种子的只读评估；只保存行为统计，评估轨迹不会进入 PPO 或经验库。已有完整行为资料的检查点不重复校准。新评估更全面，耗时不能沿用旧版每轮估计。

## 训练对手

每 32 局（16 个种子各交换学习者座位）：

| 对手角色 | 局数 | 选择 |
|---|---:|---|
| champion | 8 | 当前冠军固定参加 |
| recent | 8 | 最近两个非冠军候选 |
| diverse | 8 | 与冠军及近期候选不同的三个历史模型 |
| current | 4 | 当前模型自对弈 |
| heuristic | 4 | 基础经营对照 |

仍有 8 局确定性探测：前三组各 2 局，最后 2 局在 current / heuristic 间按迭代轮换，保留同种子双座位配对。其余 24 局使用原 20% 探索混合策略。确定性及历史模型决策不进入 PPO，盈利经验可供独立辅助学习。

建议使用 32 的倍数。较小批次按上述角色顺序截断，不保证五类都出现；缺少近期/多样性历史模型时，对应角色回退冠军，日志仍能看到实际 `opponent_slot`。

## 行为资料与对手保留

在相同固定种子的确定性对 heuristic 评估中统计：

- 九种产品的实际销售收入占比；
- 前 12 天的市场支出占总市场支出的比例；
- 混合路线占所有执行路线的比例。

成交数据来自模拟器实际结算规则的只读重放，包含返仓后出售、部分成交、购买和订单上限，不把提交的销售数量当作成交量。这些资料只用于训练调度和诊断，不加入策略输入。

行为距离 = 70% 收入占比分布的总变差距离 + 15% 前期投入比例差 + 15% 混合路线比例差。它衡量有限的经营特征，不能保证所有战术差异都被捕捉。

训练池上限 8。保护冠军、最近两个候选，剩余名额逐个保留与已选队伍最不同的历史模型。模型轮次不同本身不视作经营方式不同。

## 入池和晋级

固定验证保留原有四项指标，便于与历史日志比较。晋级不再要求不断刷新 heuristic 的现金差：其作用是基础护栏——候选有生产、平均现金 > 3000，且自身现金不少于冠军的 90%。

每次另建对手组：冠军、最近候选、行为不同的历史模型，去重后最多三个。使用新的轮换种子比较候选和冠军：

- 对冠军本人的基准是现金差 0、胜负积分 0.5；
- 对其他成员，候选和冠军分别在同种子同座位下对同一成员比赛；
- 现金优势使用 `mean_margin / (2 * mean_cash - mean_margin)` 归一化，跨对手等权；胜负积分为胜率 + 0.5 × 平局率；
- 全部对手上有实际生产且平均现金 > 3000，平均现金优势提升和平均胜负积分提升同时为正，才进入复核；
- 复核使用不重叠的另一批种子，数量是初筛的两倍；仍满足条件才 `promoted=true`。

两种额外训练池准入理由：

1. `competitive`：在轮换评估中对某成员胜率 > 50%、现金差 > 0；如果该成员不是冠军，还要求优于冠军对该成员的归一化现金优势且胜负积分不下降。避免相同策略靠打弱对手反复入池。
2. `distinct_behavior`：与池内所有模型的最小行为距离 >= 0.08，固定对照现金不少于冠军的 80%，并且对手组中均有生产、平均现金 > 3000。该名额允许盈利的新经营方式在打赢冠军前参与训练。

这些阈值是本轮实验的初始设置，不是统计显著性保证。入池不代表成为最佳模型；`best.json` 仍只随成功复核晋级更新。

默认四个初筛种子及八个复核种子按 `eval_seed + 1_000_000 + iteration * (4 * 种子数)` 分块；初筛使用块首段，复核用接下来的双倍长度。每轮不同，恢复后可复现，与固定种子、训练种子隔离。CLI 拒绝重叠；独立评估也拒绝已用于模型选择的种子范围。

对手组满三个时，一次常规评估实际 72 局；触发复核时 152 局。对手不足时减少。`evaluation_games_executed` 记录实际评估局数；启动校准另计。

## 独立保护的经验名额

每个对手来源（heuristic / current / historical）最多 48 局，互不抢占；无来源的旧经验临时放入 legacy，三个有效来源各积累 8 局后移除 legacy。

每个来源内部按以下顺序选择**不重复的对局**：

1. `elite`：最高真实利润的 16 局。不会因为新经营方式出现或时间变旧而被淘汰；更高质量的经验可以替换。
2. `recent`：剩余经验中最新的 16 局。
3. `diverse`：剩余经验中按生产类型位集合的差异挑选 16 局，优先覆盖不同经营方式。

三个区有独立名额。抽样均匀选择来源、非空区域、对局、决策；同一对局只出现一次。每局最多 32 条决策，每次辅助学习仍最多 256 条，保留原有盈利/实际收获/正后续现金回报筛选。已有旧经验在恢复时迁移到这些区域；恢复后的新格式保持区域和抽样可复现。

正常最多 144 局，迁移期间含 legacy 最多 192 局。精英按来源内绝对利润选取，仍可能受到种子难度和具体对手版本影响；这次主要保证优秀、近期和不同经营方式之间不会再次相互挤占。

## 看哪些新字段

- `games[].opponent_role`：冠军、近期、多样性、自对弈或 heuristic；实际版本用 `opponent_slot` 对应 `opponent_pool_before`。
- `experience_composition.*.buckets`：每区的数量、最旧/最新轮次。elite 应允许跨较长时间保留，recent 应持续推进。
- `admission_reason`、`behavior_novelty`、`behavior_profile`：为何入池、行为差异来自哪里。
- `panel_iterations`、`screen`、`confirmation`：真正控制晋级的对手组、种子、综合表现；`confirmation=null` 表示没有进入复核。
- `greedy_vs_champion` 仍是固定种子的对照结果，不能单独解释新晋级决定。

本次没有提高路线工作量奖励、修改网络输入或扩大规划器搜索。实验重点是是否稳住优秀能力、对不同经营方式提升收益，以及探索成果能否在确定性执行中保留。
