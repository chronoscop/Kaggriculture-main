# conditional_trial：25轮复盘

只读取现有记录，未追加训练或修改策略。实际 manifest 为25轮，非脚本默认20轮。

## 结果

- 25轮无晋级，已验收revision仍为1。
- 固定16局面板：底座得分率75%；第5/10/15/20/25轮分别75%、62.5%、68.75%、81.25%、81.25%。仅4个种子换座、2类对手，不能作为泛化胜率。
- 第20轮初筛24局：95.83% vs 83.33%；独立复核48局：72.92% vs 72.92%，无平均得分增益。
- 第25轮初筛24局：66.67% vs 75%。因此无晋级不能归咎于要求过高。

## 想要的能力有没有出现

固定面板的candidate games_detail：第5、15、20、25轮没有conditional=true批次。第10轮有6个条件胡萝卜地块，全部到期失败。后两次固定面板上涨没有伴随新的条件生产段。

200条候选训练轨迹按5轮分组：条件批次2、17、2、0、0。第二组17个仍挂在批次中的条件地块仅1个产出、16个失败；第三组2个地块都失败。不能从最终批次表还原被部分修订移除的全部历史阶段。

comparisons按candidate_set_id去重：360个完整集合、100个训练seed，168个集合候选得分不同，50个存在优于冻结菜单底座的选项。不是全部方案无效，也不是没有有用标签。

相对各集合第0项的实际终局得分：

这些是自适应训练局面上的回顾统计，分支/同种子不独立，不能解释为策略总体胜率。

延期分支记录的条件地块共452次，225次产出、227次到期；立即安排分支512次，190次产出、322次到期。这些执行摘要统计整条分支中的条件批次，可能包含候选前缀已建批次，不能一概当作被比较动作本身的完成率。

## 代码事实和解释边界

plan_menu::build_conditional 优先占位“动物延期/立即”，品种依公开商店需求和day轮换，数量偏好最多2格。它保障了时序覆盖，但没有证明这一菜单在当前局面具有经营优势。它也并不是完整、自由的经营策略搜索空间。

当前目标和拒绝理由均为终局得分；不要为救曲线再加入现金奖励。条件计划能执行的单元/引擎测试，也不能证明真实复杂经营中可靠兑现，更不能证明它比底座有利。

数据支持：本次提供的条件方案负向对照多于正向，后期确定性策略不采用条件计划。学习回避这类方案可以符合当前数据，不能仅凭这种回避认定优化器坏了。尚未解释为什么27个延期正向分支没有形成可泛化的条件规则，不能说网络本身没有问题。

## 下一步边界

不建议原样长训或放松晋级。优先追踪真实对照中的计划失效：区分资源/时序承诺未兑现，以及兑现后仍损害比赛结果；同时分析正向与负向方案在可见局面上是否可区分。对候选生成和兑现质量负责，不再把增加一个计划字段、菜单类别或通过执行测试当作训练方法已成立。

目标仍是DECEM回放体现的连续生产与按条件调整；这些行为不等于偏好转动物，也无法推出DECEM使用的训练算法。当前证据不支持承诺本方案达到该水平。
