# PFSP focus 退步诊断

## 范围

检查 `mixed_v7_pfsp_focus_trial` 第 1926–1975 轮（1600 局），以及 1925、1940、1975 检查点。本次没有修改训练实现、检查点或启动续训。

## 主要证据

1. **策略和价值损失共用 context 网络。** `learning/policy.rs` 的 `forward` 用同一个 z 生成策略类别、候选打分和价值；`update_batch` 将策略损失与 0.5 倍价值均方误差相加后统一反传、全局裁剪梯度和 Adam 更新。
   - 从 1940 对固定 1925 采集 4 个新种子、交换位置共 8 局，获得 1728 个实际 PPO 样本。采样使用 ε=0，保留采集器原有贪心探测排除规则。
   - 用相同 tanh、层级概率、损失实现审计；价值和 logp 与原生采样逐批校验，误差小于 1e-4；logp 最大误差 3.82e-6。
   - 样本固定随机打乱后分为 7 个批次：价值损失对共享层的梯度范数为策略损失的 13.4–41.2 倍，中位数 16.1 倍；3/7 批次两个梯度内积为负。
   - 这证明本批数据中存在共享表示的强梯度干扰；梯度比不等于 Adam 后参数位移比，也不能单独证明它解释全部退步。
2. **成功经验保护会随价值估计改变而减弱。** `imitate` 权重是 clamp(mc_return - current_value, 0, 1)，每轮仅执行一次独立辅助更新。
   - 固定使用 1940 银行中的 48 局 elite，共 1477 个决策，分别由 1940 和 1975 网络重新计算。
   - 平均权重 0.716 → 0.583；零权重占比 0.54% → 10.70%。这是固定样本比较，没有混入经验库换样影响。
   - 对历史路线动作的确定性一致率 97.83% → 94.70%；历史投资动作一致率均为 97.44%。整体已选动作的平均概率反而 0.731 → 0.740，因此不能说模型全面遗忘或所有成功动作概率下降。
   - 经验保留本身生效：1975 仍保留早至 1862–1886 轮的 elite。不是旧优秀局又被全部淘汰。
3. **保护未覆盖完整更新。** 每轮约 57–60 次 PPO 小批次更新后，仅一次 256 行辅助回放；更新次数不能直接等同于梯度强弱。KL 检查只在 PPO 小批次更新前进行，没有整个 PPO+回放完成后的全样本 KL 复核或回滚。50 轮 `kl_stopped` 均为 false；这不证明策略没有漂移。小 KL 也不保证确定性 argmax 不翻转。

## 已排除或尚未证实

- 未发现当前诊断样本的旧 logp/前向概率不一致、现金回报公式中的明显符号或终局错误。
- 新对手调度和长期经验配额生效。尚无证据把这次退步归因于对手抽样失败。
- 现金目标与胜负目标不完全相同，但本次没有因果证据证明它是主因，不建议同时大改奖励。
- 8 局梯度诊断及固定 elite 样本不代表全部状态；要确认修复收益，仍需隔离干扰后的短对照训练。

## 建议修复顺序

1. 优先拆开 actor/critic 的 context 特征提取，阻止价值回归直接改写策略表示；从旧检查点复制原 context 到新 critic，迁移时验证策略输出、价值输出不变，显式处理新增参数和优化器状态。
2. 对经过筛选的 elite 采用不被当前 critic 一票归零的受限保持项，并将其纳入训练步；recent/diverse 仍允许价值优势筛选。补有效回放行数、权重、策略/价值损失和共享梯度等日志。
3. 增加完整更新后的策略偏移检查。短对照先隔离 actor/critic 干扰，再验证经验保持改动，避免同时改奖励、对手或模型规模而无法解释结果。
