# 动态路线 RL（v2）

## 决策职责

同一个网络按工人轮流、逐项生成工作路线。每次动作是目标地格和工作种类，
不是整条预设路线。每轮选择后立即更新一份共享规划状态，下一次选择读到更新后的状态。
所有工人均由这一层控制。默认从 step 0 开始，不调用 baseline 调度本方工作。
baseline 仅用于对手、独立基准对局，以及显式指定的 `--takeover` 暖启动实验。

可选工作包括收获、五种作物种植、浇水、施肥、喂养、照料、收肥、建鸡舍/牧场、
放养三种动物、清地、仓库取货/返仓、销售、采购、雇工、购地、等待和结束。
喂养与照料是独立选择，网络可以降低服务强度。
不按利润或距离取 top-k，不限制每天只能两条路线，也不固定第 6–12 天扩张。
采购每次选择一个单位；取货和销售可选择一个单位或当前全部可用数量。
市场动作保守地占用所分配工人的一个计划时段。

土地变化由相邻决策衔接：收获一次性作物后立即可选种任何作物或建设施；
多年生作物及闲置设施可用 DIG 清除。已放养动物不能直接出售、移走或 DIG：
引擎中连续两天未喂会离开，之后才可清地复耕。网络通过是否安排喂养决定保留，
没有添加虚构的动物退出指令。

## 共享状态与预留

`PlanningState` 深拷贝当前观察，保存预测地图、种子、仓库、每个工人的背包、
位置、已用工时、现金估计以及资源依赖账本。每提交一个工作：
1. 消耗移动、操作和依赖等待的时间；
2. 更新目标地格、库存、背包及预计收支；
3. 将相关地格、种子、仓库或现金的最后使用者记为该工作；
4. 后续使用相同资源的工作依赖其实际执行成功。

同一份收获、种子、饲料、肥料或资金不会被重复分配。不同地格可以并行操作。
仓库和现金采用较保守的整体串行依赖，防止库存回执混淆及容量冲突；
它目前牺牲一部分并行效率，未来可细分资源数量预留，但不能取消执行确认。

默认规划到当日结束，最长 24 个行动时段；每名工人最多构造 24 项。
每天结束雇工会消失、背包自动回仓，因此不把旧工人身份和背包假设带到次日。
跨季节的土地投资由连续整局决策和回报学习，当前不预测跨日生长来构造多日任务队列。

## 销售融资与执行

销售只产生计划中的估计现金。可以据此生成条件采购及其下游取货、放养工作，
但估计收入不授权真实采购。例如：

```text
A：收羊毛 → 返仓 → 销售
                       ↓ 确认库存减少和实际现金增加
B：收小麦 → 建牧场 → 买羊 → 确认入库 → 取羊 → 放养
```

移动按确定性路径展开，可以提前前往等待地点。
工作必须在所有依赖确认后，重新通过真实状态合法性检查才会发出。
订单以实际库存增减和现金方向确认，不使用“库存里本来就有一只羊”作为采购成功证据。
若售价下降、订单失败或世界变化使动作不再成立，会释放计划并从真实状态重建；
销售后现金不足不会继续取货或放养。计划不把多个依赖订单塞入同一回合来赌到账。

默认每 6 回合滚动重排，也会在路线全部完成、失败、跨日、雇工或购地到账时重排。
因此最长只有有限时段的承诺，剩余安排可适应市场变化。参数可通过
`--horizon` 和 `--replan-interval` 调整。不合法动作导致的重排在下一次 act 执行，
当前回合未获得合法工作的工人等待。

## 网络和训练

共享上下文编码完整的 10×10 预测地图、作物和动物状态、市场、库存、
现金及销售估计、工人在预测终点的分布与已占用工时。
逐项动作编码目标状态、品种、操作、工人背包、距离相关位置、完成时间和依赖等待。
候选数量可变，仅在 PPO minibatch 内补齐并屏蔽 padding；不存在固定 24 条模板菜单。

每次路线构造选择均写入同一局轨迹。构造阶段没有虚构收益；
引擎每回合的实际双方现金差变化记在最近一次选择上，gamma=1、lambda=1
将未来实际现金回报传到早期投资。任务数、行走、重排或等待不作为经济奖励。
默认 step 0 接管，轨迹累计奖励乘 10000 等于终局双方现金差减初始现金差。
显式暖启动时只累计接管后的差值变化。

引擎的完整赛季是对 step 0..718 做 719 次行动，在 step 719 读取终局现金。
这是环境约定，不应额外执行第 720 次。训练每轮同一种子双座位两局，
固定种子 9001/9002 的四局用于模型选择，另用未参与选择的种子评估。

轨迹特征用紧凑 CPU tensor 缓存，PPO 逐批传到训练设备。
v1 模板模型与 v2 输入和动作语义不兼容，加载时明确拒绝，必须重新训练。
checkpoint 保存规划参数，评估默认复用这些参数；显式覆盖用于消融实验。

## 验证与边界

单元测试覆盖混合路线构造、共享任务/物料/现金预留、未到账阻塞、销售不足、
跨日重置和延迟回报。构建 Rust 后，同一测试入口还验证：
- 取饲料、服务动物、收肥施肥、收麦换草莓、返仓的完整实际动作流；
- 一名工人的羊毛收入资助另一名工人的羊只采购和放养；
- 动物连续未喂离开后清地复耕。

`route-rl-evaluate --trace-dir ...` 可记录规划中的工作 ID、依赖 ID、
预计完成时间、实际动作与到账确认。用日志区分“计划过”与“实际完成”。

这是动态路线训练实现，不是已训练好的强策略。短训练不能证明胜率。
从零探索包含清地、建设和等待等大量合法低收益选择；整季信号方差较大，
需要用独立种子现金差、胜率和实际执行日志判断收敛。
周期重排可能取消尚未执行的计划尾部，这些构造选择仍属于策略轨迹，
会增加信用分配噪声。当前实现没有未来市场价格预言，也不保证复现任何特定选手的扩张时机。
