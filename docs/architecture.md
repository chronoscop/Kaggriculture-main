# Route RL 架构

局部动作不是单格作物标签，而是一名工人的完整短路线。候选包含继续 baseline、收获后续种与返仓、五种作物种植、三种动物的建设/取货/放养、喂养照料，以及收肥后给附近作物施肥。最多保留 24 条，模型对可用候选打分。没有活动路线时，在冷却结束或回款、土地释放、购地、商店变化后重新选择；每日最多启动两条。

执行器逐回合检查真实观察。采购订单在市场结算后到账，下一回合确认种子或动物实际入库，才继续路线。工人移动、操作和返仓依照规则分步执行；目标被其他工人占用或资源不足时跳过或终止。销售订单排在相关采购之前，买到的物资不能在同回合单位动作中使用。其他工人保持 baseline 的经营动作。

训练使用 `third_party/kaggriculture-simulation` 的 `kagg serve` Rust 引擎，719 次行动后读取终局现金。奖励是双方现金差的真实变化，未折扣累计到终局。PPO 的路线零始终是 baseline；固定双座位对局用于模型选择，独立种子用于最终评估。`route-rl-check` 可用官方 1.32.7 引擎对 Rust 执行同一动作流并比较每步完整状态。

这是可训练的起点，不是已经达到大肥鱼或超过 baseline 的模型。当前候选只接管一名工人的短路线，baseline 的内部计划不知道其任务被改写；畜群主动退出、多个工人共同改排路线也尚未成为显式动作。训练后的整局现金结果必须验证这些局限有没有影响收益。
